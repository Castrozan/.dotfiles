### Avatar Rust rewrite research

The brief for your topic is the file named on the next line.
$INPUTS.topic_path

Read it first. It names the topic, the questions to settle, and the context files to read. Research externally with web
search and the GitHub CLI (`gh api`, read only), and read the named local files. Change no file.

### Method

Prefer evidence to reputation: last commit date, release cadence, CI configuration, test layout, and the real
configuration files of each repository you name. Open a repository's own files rather than summarizing its README.
Every decision carries at most five sources, each a full URL or a repository path with a commit or tag. Seek at least one
disconfirming source for each decision before keeping it. List the options you rejected with one line of reason each.
List unknowns that you could not settle, so the owner sees the limit of the evidence.

Return only the structured output. Keep each decision under 80 words.
