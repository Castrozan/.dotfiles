# Agent Behavior

The instruction surface did not fail because it was small. It failed at behavioral placement: abstract guidance remained
always-on while operational defaults moved to surfaces that might not remain available for as long as the behavior had
to hold. This document defines the filing discipline for behavior; it does not restore the old core.

## What broke

The reported result is little visible change from the retained guidance and regressions in removed defaults such as the
comment policy. That observation identifies a gap without proving that placement caused every miss. The concrete defect
is inferential: a model can understand and recall a principle without choosing the owner's default action.

## The design

Enforce non-negotiable behavior in code when a precise predicate can handle its exceptions without unacceptable false
results. Hooks, permissions, assertions, and CI survive recall failure and compaction; a fragile policy parser does not.
Match every remaining instruction's surface to its scope and horizon. Universal session-long behavior belongs in global
core; repository-wide behavior in its `CLAUDE.md`; file-scoped behavior in path rules; harness mechanics in the harness.
Skills own bounded procedures, reference material, and tool operation. Core may route a bounded operation to a skill,
but it must not outsource a persistent default to a skill body loaded on demand. Core is behaviorally complete, not
maximal; `<coding>` earns a place only for universal, non-enforceable defaults needed throughout coding.

## Write contract and guard

A core rule is non-negotiable, global, session-long, not safely enforceable, and observable. State its trigger, act, and
exception. If it fails scope, narrow its owner; if it fails duration, use a skill; if code can decide it safely, enforce
it. Test ordinary work without naming the rule, including multiple turns and compaction when duration matters.
Research on rule inference, recall without adherence, multi-turn decay, and constraint saturation supports these risks.
Anthropic's Claude Code guidance assigns persistent context to `CLAUDE.md`, bounded procedures to skills, and reliable
automation to hooks. This evidence does not prove this repository's exact placement decisions.
