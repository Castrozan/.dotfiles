### Public references

Invoke `shorten-url` for long, publicly shareable reference URLs. The service is TinyURL; submitting a destination
shares it with that service. Keep private, authenticated, credential-bearing, and expiring URLs direct. Required
artifact links follow the session's [artifact links](../../../interactive-communication.md#artifact-links).

### Reply rendering

Use the verified result as a bare URL and identify its destination in nearby prose. If the command fails, keep the
original URL. Follow the session's [link format](../../../interactive-communication.md#link-format).
