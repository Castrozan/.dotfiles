### Visual direction

Read [Anthropic's frontend design guidance](references/anthropic-frontend-design.txt). Derive concrete visual constraints
from the brief while preserving the user's design system and the [humanize](../humanize/SKILL.md) writing rules.

### Page composition

Keep complete page assembly in [page-composer](../page-composer/SKILL.md#workflow-boundary). Pass the resulting palette,
typography, layout, motion and accessibility requirements through its `constraints`. Apply the visual guidance directly
when styling components or revising an existing interface.
