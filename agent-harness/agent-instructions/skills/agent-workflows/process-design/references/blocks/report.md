### What it gives

The process's outward result: a ticket comment, a reply to the requesting agent, a chat message, or a published report.

### Use when

Anyone outside the process must learn the outcome. Every outward report is owner-gated unless standing approval covers
it.

### Instruction

Draft the report from the tracker, show it at its gate, and publish only after approval.

### Harness

Ticket, chat, and forge integrations; an A2A reply for an orchestrating peer.
