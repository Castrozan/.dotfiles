### Provider and assembly limits

Movie assembly does not establish creative quality or verify that narration expresses a requested feeling. Inspect the
finished artifact against the script. Caption alignment belongs to the selected speech model; available timestamps do
not imply that the movie assembler burns captions. Discovery states whether captions and music are assembled.

### Billing boundary

OpenAI and Replicate API credentials have their own billing. An interactive image tool in an agent session does not
provide a headless API credential. Unknown dollar charges must stay unknown until reconciled with provider evidence.
