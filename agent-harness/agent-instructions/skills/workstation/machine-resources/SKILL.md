### Optimize never remove

Never close, stop, or kill the apps, browsers, agent sessions, or tools the user works with to free resources. Find why
each consumer costs what it does, measure process families before and after, and cut that cost where its configuration
is owned: duplicated children, leaks, polling, oversized caches, and idle workers.
